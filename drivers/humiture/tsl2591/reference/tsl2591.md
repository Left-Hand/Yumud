## 一、简介
TSL2591 是一款高灵敏度的光转数字转换器，可将光强转换为数字信号，依托标准 **I²C 接口** 完成通信，无需额外外部信号调理电路，数字输出抗干扰能力强，适配各类嵌入式控制器。

该芯片集成两路光电二极管：一路为宽带光电二极管（响应可见光+红外光），另一路仅对红外光响应；搭配双路 ADC 可将光电流转为数字辐照度数据，结合经验公式即可换算为照度值（单位：lux），模拟人眼感光特性。

芯片支持**中断功能**，无需主控持续轮询读取光强，可灵活配置光强上下阈值、阈值触发持续时长，以此判定光强“显著变化”。中断分为两种模式：一种需光强持续超出阈值指定周期后触发；另一种检测到光强超限后立即触发，有效简化系统设计、降低功耗。

## 三、寄存器介绍
### 1. 使能寄存器（0x00）
该寄存器用于控制 TSL2591 启停与各类功能使能。

| 位号 | 名称   | 功能说明                                                     |
| ---- | ------ | ------------------------------------------------------------ |
| 7    | NPIEN  | 置1时，光照超出中断阈值**立即触发中断**，忽略持久过滤器       |
| 6    | SAI    | 置1时，中断产生后，当前光强采样周期结束芯片自动进入休眠模式  |
| 5    | 保留位 | 固定置0                                                      |
| 4    | AIEN   | 置1时，开启ALS光强中断，触发规则受持久过滤器限制             |
| 3:2  | 保留位 | 固定置0                                                      |
| 1    | AEN    | ALS光强感应功能使能：1=开启，0=关闭                          |
| 0    | PON    | 内部振荡器总开关：1=芯片上电工作，0=芯片下电休眠             |

### 2. 控制寄存器（0x01）
用于配置芯片复位、信号增益、光强采样积分时间。

| 位号  | 名称    | 功能说明                                                     |
| ----- | ------- | ------------------------------------------------------------ |
| 7     | SRESET  | 系统复位位：写1触发芯片复位，执行后该位自动清零              |
| 6     | 保留位  | 固定置0                                                      |
| 5:4   | AGAIN   | 增益配置：<br>00 = 低增益<br>01 = 中增益<br>10 = 高增益<br>11 = 最大增益 |
| 3     | 保留位  | 固定置0                                                      |
| 2:0   | ATIME   | 采样积分时间配置：<br>000 = 100 ms（最大计数36863）<br>001 = 200 ms（最大计数65535）<br>010 = 300 ms（最大计数65535）<br>011 = 400 ms（最大计数65535）<br>100 = 500 ms（最大计数65535）<br>101 = 600 ms（最大计数65535） |

### 3. ALS 中断阈值寄存器（0x04 − 0x0B）
该组寄存器共8个字节，分为**带持久阈值**和**无持久阈值**两类，以通道0数据（C0DATA）作为判定依据：数据低于低阈值、或高于高阈值时触发中断。
1. 带持久阈值（0x04~0x07）：数据超限且持续指定周期后触发中断；
2. 无持久阈值（0x08~0x0B）：数据超限后，当前积分周期结束立即触发中断。

中断引脚输出信号，需配合使能寄存器的 `AIEN` 或 `NPIEN` 位开启才会生效；芯片上电后，该组寄存器默认值均为 `0x00`。

| 寄存器地址 | 名称      | 位范围 | 说明                     |
| ---------- | --------- | ------ | ------------------------ |
| 0x04       | AILTL     | 7:0    | ALS 低阈值低字节         |
| 0x05       | AILTH     | 7:0    | ALS 低阈值高字节         |
| 0x06       | AIHTL     | 7:0    | ALS 高阈值低字节         |
| 0x07       | AIHTH     | 7:0    | ALS 高阈值高字节         |
| 0x08       | NPAILTL   | 7:0    | 无持久ALS低阈值低字节    |
| 0x09       | NPAILTH   | 7:0    | 无持久ALS低阈值高字节    |
| 0x0A       | NPAIHTL   | 7:0    | 无持久ALS高阈值低字节    |
| 0x0B       | NPAIHTH   | 7:0    | 无持久ALS高阈值高字节    |

### 4. 持久过滤器寄存器（0x0C）
用于设置**连续超限采样周期数**，仅对带持久阈值的中断生效，无持久中断不受该寄存器影响。芯片上电默认值为 `0x00`。

| 位范围 | 名称   | APERS（二进制） | 功能说明                     |
| ------ | ------ | -------------- | ---------------------------- |
| 7:4    | 保留位 | -              | 固定置0                      |
| 3:0    | APERS  | 0000 (0x0)     | 每个采样周期均触发中断       |
|        |        | 0001 (0x1)     | 单次超限即触发中断           |
|        |        | 0010 (0x2)     | 连续2次超限触发中断          |
|        |        | 0011 (0x3)     | 连续3次超限触发中断          |
|        |        | 0100 (0x4)     | 连续5次超限触发中断          |
|        |        | 0101 (0x5)     | 连续10次超限触发中断         |
|        |        | 0110 (0x6)     | 连续15次超限触发中断         |
|        |        | 0111 (0x7)     | 连续20次超限触发中断         |
|        |        | 1000 (0x8)     | 连续25次超限触发中断         |
|        |        | 1001 (0x9)     | 连续30次超限触发中断         |
|        |        | 1010 (0xA)     | 连续35次超限触发中断         |
|        |        | 1011 (0xB)     | 连续40次超限触发中断         |
|        |        | 1100 (0xC)     | 连续45次超限触发中断         |
|        |        | 1101 (0xD)     | 连续50次超限触发中断         |
|        |        | 1110 (0xE)     | 连续55次超限触发中断         |
|        |        | 1111 (0xF)     | 连续60次超限触发中断         |

### 5. ALS 数据寄存器（0x14 - 0x17）
存储两路光电通道的16位原始采样数据，共4个字节。芯片内置影子寄存器机制：读取任意通道低字节时，对应高字节会自动锁存，保证高低字节数据来自同一个采样周期，避免数据错乱。

建议按顺序连续读取4个字节，减少两路通道数据不同步问题。

| 寄存器地址 | 位范围 | 字段名   | 说明                  |
| ---------- | ------ | -------- | --------------------- |
| 0x14       | 7:0    | C0DATAL  | 通道0 数据低字节      |
| 0x15       | 7:0    | C0DATAH  | 通道0 数据高字节      |
| 0x16       | 7:0    | C1DATAL  | 通道1 数据低字节      |
| 0x17       | 7:0    | C1DATAH  | 通道1 数据高字节      |
