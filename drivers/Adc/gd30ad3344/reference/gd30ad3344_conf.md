## 配置寄存器字段说明
| 位 | 字段 | 类型 | 复位值 | 描述 |
| ---- | ---- | ---- | ---- | ---- |
| 15 | OS | R/W | 0h | 运行状态/单次转换启动<br>仅掉电状态可写入，转换中写入无效<br>0=无效；1=启动单次转换；读回始终为0 |
| 14:12 | MUX[2:0] | R/W | 0h | 输入多路复用器配置<br>000=AIN0正/AIN1负（默认）<br>001=AIN0正/AIN3负<br>010=AIN1正/AIN3负<br>011=AIN2正/AIN3负<br>100=AIN0正/GND负<br>101=AIN1正/GND负<br>110=AIN2正/GND负<br>111=AIN3正/GND负 |
| 11:9 | PGA[2:0] | R/W | 2h | 可编程增益放大器（FSR配置）<br>000=±6.144V<br>001=±4.096V<br>010=±2.048V（默认）<br>011=±1.024V<br>100=±0.512V<br>101=±0.256V<br>110=±0.064V |
| 8 | MODE | R/W | 1h | 工作模式<br>0=连续转换模式<br>1=掉电/单次模式（默认） |
| 7:5 | DR[2:0] | R/W | 4h | 数据速率配置<br>000=6.25SPS<br>001=12.5SPS<br>010=25SPS<br>011=50SPS<br>100=100SPS（默认）<br>101=250SPS<br>110=500SPS<br>111=1000SPS |
| 4 | Reserved | R/W | 0h | 保留位，写入0/1均无效 |
| 3 | PULL_UP_EN | R/W | 1h | DOUT/DRDY上拉使能<br>仅CS为高时生效，内部400kΩ上拉<br>0=禁用上拉；1=启用上拉（默认） |
| 2:1 | NOP[1:0] | R/W | 1h | 无操作控制<br>00/10/11=无效数据，不更新配置<br>01=有效数据，更新配置（默认） |
| 0 | Reserved | R | 1h | 保留位，写入0/1均无效，读回始终为1 |
