# 1 通信接口介绍
## 1.1 引脚定义与接线
Rd-03 模块共 5 个引脚，采用 TTL 电平串口通信。

| Rd-03 | USB to TTL | 说明 |
| :--- | :--- | :--- |
| 3.3V | 3.3V | 电源 |
| GND | GND | 地 |
| RX | TXD | 串口接收 |
| OT1 | RXD | 串口发送 |
| OT2 | - | 人体状态输出：无人低电平，有人高电平 |

## 1.2 配置参数及说明
可通过串口修改雷达检测参数，暂不支持修改阈值。

| 参数名称 | 可选范围 | 说明 |
| :--- | :--- | :--- |
| 最大检测距离门 | 0~15 | 1 个距离门 = 70cm |
| 目标消失延时 | 0~65535 | 有人→无人延时，单位：秒 |
| 调试模式 | 固定 | 串口上报 RDMap（上位机解析） |
| 运行模式 | 固定 | 串口打印状态 |
| 上报模式 | 固定 | 上报各距离门能量值与检测结果 |

# 2 通信协议
串口默认参数：**115200 波特率、1 停止位、无校验**  
数据格式：**小端模式**，所有数据为十六进制。

## 2.1 协议格式
### 2.1.1 协议数据格式
采用小端格式。

### 2.1.2 指令协议帧格式

#### ACK 帧内数据（表 6）

## 2.2 带应答的发送指令
### 2.2.1 开启配置模式
必须先发送此指令，后续配置才有效。
- 指令字：`0x00FF`
- 指令值：`0x0001`
- 返回：2 字节状态(0=成功) + 2 字节版本 + 2 字节缓存大小
- 发送：`FD FC FB FA 04 00 FF 00 01 00 04 03 02 01`
- 应答成功：`FD FC FB FA 08 00 FF 01 00 00 01 00 40 00 04 03 02 01`

### 2.2.2 关闭配置模式
退出配置，恢复雷达工作模式。
- 指令字：`0x00FE`
- 指令值：无
- 返回：2 字节状态(0=成功)
- 发送：`FD FC FB FA 02 00 FE 00 04 03 02 01`
- 应答成功：`FD FC FB FA 04 00 FE 01 00 00 04 03 02 01`

### 2.2.3 参数配置指令（0x0007）
用于配置距离门、目标消失延时等。

| 参数名称 | 参数字 |
| :--- | :--- |
| 最小检测距离门 | 0x0000 |
| 最大检测距离门 | 0x0001 |
| 检测目标最小帧数 | 0x0002 |
| 目标消失最小帧数 | 0x0003 |
| 目标消失延时 | 0x0004 |

- 指令字：`0x0007`
- 指令值：2 字节参数字 + 4 字节参数值
- 返回：2 字节状态(0=成功,1=失败)

示例（设置最大距离门 3）：
`FD FC FB FA 08 00 07 00 03 00 00 00 04 03 02 01`

### 2.2.4 参数读取指令（0x0008）
- 指令字：`0x0008`
- 指令值：2 字节参数字
- 返回：2 字节状态 + 4 字节参数值

示例应答：
`FD FC FB FA 08 00 08 01 00 00 03 00 00 00 04 03 02 01`

### 2.2.5 系统参数配置（0x0012）
| 参数名称 | 参数字 | 说明 |
| :--- | :--- | :--- |
| 调试模式 | 0x00 | 上报 RDMap |
| 上报模式 | 0x04 | 上报能量值与结果 |
| 运行模式 | 0x64 | 打印状态 |

- 指令字：`0x0012`
- 指令值：2 字节参数字 + 4 字节值
- 返回：2 字节状态

示例（设置调试模式）：
`FD FC FB FA 08 00 12 00 00 00 00 00 00 00 04 03 02 01`

## 2.3 雷达数据输出协议
默认输出目标状态与运动距离；上报模式额外输出各距离门能量值。

### 2.3.1 上报数据帧格式
#### 工作模式（表 9）
| 目标状态 | 运动距离 |
| :--- | :--- |
| ON | 距离(cm) |
| OFF | 无 |

#### 调试模式帧（表 10）
| 帧头 | 数据 | 帧尾 |
| :--- | :--- | :--- |
| 0xAA,0xBF,0x10,0x14 | 20*16*4 字节 | 0xFD,0xFC,0xFB,0xFA |

#### 上报模式帧（表 11）
| 帧头 | 数据长度 | 结果 | 目标距离 | 16 个距离门能量 | 帧尾 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0xF4,0xF3,0xF2,0xF1 | 0x0023 | 有人/无人 | 2 字节 | 16*2 字节 | 0xF8,0xF7,0xF6,0xF5 |

## 2.4 雷达指令配置模式
### 2.4.1 配置步骤
1. 发送**开启配置模式**
2. 发送参数读写指令
3. 发送**关闭配置模式**，恢复检测

### 2.4.2 注意事项
1. 单条指令最大长度 ≤64 字节
2. 字节序：**小端**
3. 进入指令模式前建议清空串口缓存
4. 自定义指令 ID 推荐：`0x0060 ~ 0x00A0`
