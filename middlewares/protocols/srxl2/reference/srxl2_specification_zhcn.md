## 5 电气参数
1. 供电范围：舵机总线电压 **3.5V ~ 8.4V**
2. 信号电平：标准3.3V逻辑电平，空闲总线为高阻态，搭配芯片内部弱上拉
3. 总线供电：仅支持低功耗设备取电，大功率舵机禁止同线供电
4. 接口类型
    - 标准3针舵机插头
    - ZH4 4针小型连接器

### 标准3针舵机引脚定义
1脚：SRXL2收发信号
2脚：总线供电 3.5V~8.4V
3脚：地线

### JST ZH4引脚定义
1脚：SRXL2收发信号
2脚：空脚
3脚：总线供电 3.5V~8.4V
4脚：地线

> 警告：老式SRXL设备引脚定义不兼容，切勿混插，避免硬件烧毁。空闲状态下信号线可兼容传统PWM舵机信号。

## 6 硬件层通信协议
### 6.1 串口UART配置
- 波特率：默认**115200bps**，可选400000bps
- 数据位：8位
- 校验位：无
- 停止位：1位
- 格式：**8N1**

### 6.2 总线通信规则
1. 总线空闲时不主动驱动电平
2. 总线主机：总线上设备ID最小的接收机/远程接收机，固定按射频数据包频率发送控制数据（常见5.5ms/11ms）
3. 一条总线仅允许存在**一台主机**
4. 从机仅可在总线空闲2个字符时长后发送数据，且未收到主机应答请求时禁止主动发包
5. 所有从机监听主机数据完成时钟同步
6. 设备优先避让主机控制数据包，禁止抢占总线
7. 主机断连超时50ms，所有设备进入重新同步、重新选举主机状态
8. SRXL2单条报文最大**80字节**（含3字节头部+2字节CRC）
9. 无关设备收到非目标数据包禁止应答，预留总线资源

## 7 软件通信协议
### 7.1 协议概述
SRXL2官方厂商识别码：**0xA6**
数据包最小长度5字节，最大80字节，仅适用于2018年6月之后研发新品。

**标准报文格式**
`0xA6 + 包类型 + 长度 + 数据载荷 + CRC高字节 + CRC低字节`
所有多字节数据默认**小端序**，仅CRC为大端序。

#### 7.1.1 设备ID定义
单字节设备ID，高4位为设备类型，低4位为同类型设备编号

| 设备类型码 | ID区间 | 设备类型 | 默认ID |
| ---- | ---- | ---- | ---- |
| 0 | 0x00 | 无指定设备 | - |
| 1 | 0x10~0x1F | 远程接收机 | 0x10 |
| 2 | 0x21~0x2F | 主接收机 | 0x21 |
| 3 | 0x30~0x3F | 飞控FC | 0x30 |
| 4 | 0x40~0x4F | 电调ESC | 0x40 |
| 5 | 0x50~0x5F | 预留 | - |
| 6~7 | 0x60~0x7F | SRXL2智能舵机 | 0x60 |
| 8 | 0x81~0x8F | 图传VTX | 0x81 |
| 9~14 | 0x90~0xEF | 预留 | - |
| 15 | 0xFF | 全局广播地址 | - |

- 0xFF：广播，所有设备接收
- 0x00：无需设备应答
- 仅一台设备可设置低4位为0，避免开机握手冲突

#### 7.1.2 数据包类型
| 数据包名称 | 类型码 | 总字节长度 |
| ---- | ---- | ---- |
| 握手包 | 0x21 | 14 |
| 绑定信息包 | 0x41 | 21 |
| 参数配置包 | 0x50 | 14 |
| 信号质量包 | 0x55 | 10 |
| 遥测传感器数据包 | 0x80 | 22 |
| 控制数据包 | 0xCD | 5~80可变 |

### 7.2 握手数据包
设备上电默认115200波特率发送，用于总线设备枚举、协商统一波特率、确定遥测优先级。

**报文格式**
`0xA6 0x21 长度 源ID 目标ID 优先级 波特率 设备信息 唯一ID CRC`
- 长度固定14字节
- 优先级：1~100，数值越高遥测上报优先级越高
- 波特率标识：0=仅支持115200，1=支持400000
- 设备信息：位域标识设备遥测、正向编程能力
- 唯一ID：32位设备唯一编号，防止同ID设备冲突

#### 7.2.1 握手流程
1. 设备上电串口初始化115200波特
2. 上电监听50ms总线数据，有通信则直接同步波特率
3. 未检测总线通信则每隔50ms发送握手包，持续200ms
4. 收到主机握手指令后应答自身最高支持波特率
5. 收到0xFF广播握手包，全局统一切换总线波特率
6. 总线50ms无主机数据，全部设备切回115200并重握手

### 7.3 绑定信息数据包
接收机完成对频后下发，支持一键进入对频模式、查询绑定状态、同步绑定信息至其他接收机。

**请求指令码**
| 指令 | 数值 | 功能 |
| ---- | ---- | ---- |
| 进入对频模式 | 0xEB | 控制接收机进入射频对频 |
| 查询绑定状态 | 0xB5 | 获取接收机绑定协议与ID |
| 绑定数据上报 | 0xDB | 接收机上报自身绑定信息 |
| 设置绑定信息 | 0x5B | 批量设置接收机绑定参数 |

**绑定协议类型**
| 类型码 | 协议制式 |
| ---- | ---- |
| 0x00 | 未绑定/退出对频 |
| 0x01 | DSM2 1024 22ms |
| 0x12 | DSM2 2048 11ms |
| 0xA2 | DSMX 22ms |
| 0xB2 | DSMX 11ms |
| 0xE2 | DSMR 11/22ms |
| 0xE4 | DSMR 5.5ms |

### 7.4 参数配置数据包
用于飞控读写外设内部配置参数，自定义参数由设备厂商定义。
- 写参数：0x57
- 查询参数：0x50
- 所有参数统一使用32位数值传输

### 7.5 信号质量数据包
用于获取接收机天线信号强度、RSSI信号值
- 请求状态：0x52
- 状态上报：0x53
- 数据格式：8位有符号数，正数=百分比RSSI，负数=dBm信号强度

### 7.6 遥测传感器数据数据包
内置16字节标准X-Bus遥测数据，可直接兼容市面主流Spektrum遥测传感器。
目标ID设为0时关闭全部设备射频遥测，设为0xFF触发设备重新握手。

### 7.7 控制数据数据包
主机下发核心飞行通道数据、失控保护数据、图传配置数据。

| 命令码 | 功能 |
| ---- | ---- |
| 0x00 | 正常通道数据 |
| 0x01 | 失控保护通道数据 |
| 0x02 | VTX图传配置数据 |

#### 7.7.1 正常通道数据
包含RSSI值、丢帧数、通道掩码、多路通道数值
- 通道中心值：0x8000
- 数值范围：0 ~ 0xFFFC
- 通道掩码为0代表信号丢失、未建立射频连接

#### 7.7.2 失控保护通道数据
射频断连后下发预设失控数值，未标注通道直接禁用，不保持上一数值。

#### 7.7.3 VTX图传配置数据
支持频段、信道、功率、竞速/静默模式、地区频段设置，支持档位功率与精准数值功率双模式。

## 8 附录
### 8.1 CRC16校验算法
采用**XMODEM CRC16**
多项式：0x1021，初始值0，无位反转

#### 8.1.1 C语言算法
```c
uint16_t Crc16(uint16_t crc, uint8_t data) 
{ 
    crc = crc ^ ((uint16_t)data << 8); 
    for(int i = 0; i < 8; ++i) 
        if(crc & 0x8000) 
            crc = (crc << 1) ^ 0x1021; 
        else 
            crc = crc << 1; 
    return crc; 
}
```

#### 8.1.2 校验使用示例
遍历报文除最后2位CRC外所有字节计算校验值，与报文自带CRC对比完成校验。

### 8.2 废弃协议
1. 单向SRXL 0xA2：2016年5月淘汰，仅传通道数据，无遥测
2. 初代双向SRXL 0xA5：2018年7月停止新项目使用，存在CRC计算BUG

### 8.3 老式废弃引脚
仅SPM4649T老设备使用，新项目禁止沿用
